# 每日时事新闻汇报 📰

一个 Windows 桌面小工具：每天打开就能看到当天时事新闻，一键汇总复制。

## 功能

| 频道 | 内容 | 来源 |
|---|---|---|
| 今日简报 | 每天约 15~30 条一句话新闻（含农历、每日一句） | 60s 看世界 |
| AI 热点 | AI 相关热门话题聚合（带来源和热度标签） | 量子位 RSS 全量 + 新浪科技与上方五频道关键词筛选 |
| 百度热搜 | 实时热搜榜 | 百度官方接口 |
| 腾讯新闻 | 新闻热榜（带热度值） | 腾讯新闻接口 |
| B站热搜 | 视频平台热搜（带热度值） | B站接口 |
| 知乎热榜 | 问答热榜（带热度值） | 知乎接口 |

> AI 热点聚合规则：量子位（纯 AI 资讯媒体）的 RSS 全量收录；新浪科技滚动新闻与今日简报、四大热榜按关键词（AI、大模型、GPT、OpenAI、DeepSeek、机器人、芯片、算力、英伟达等 60+ 个）筛选，按标题去重后合并展示，每条标注来源与热度。聚合在每次刷新后自动重建。

- 🖱 **单击**：跳转到浏览器（简报条目按标题跳转百度搜索，热搜条目打开原文）；**右键**复制单条
- 📋 **复制全部**：一键复制当前频道全部标题（含热度），方便转发
- 🔄 **自动刷新**：启动时后台静默拉取最新数据；默认每 30 分钟自动刷新
- 💾 **离线缓存**：数据保存在本地 `data/cache.json`，断网也能看最近一次内容（状态栏会标注「离线缓存」）
- 🎨 **深色/浅色主题**、**窗口置顶**，设置自动记忆

## 运行

**方式一（推荐）：桌面快捷方式或直接双击 `每日时事新闻汇报.exe`**

独立单文件程序（约 17MB），无需安装 Python 和任何依赖，像普通桌面应用一样使用。
首次双击若 Windows 提示「已保护你的电脑」（SmartScreen 对未签名 exe 的常规提示），点「更多信息 → 仍要运行」即可。

**方式二：双击 启动.bat**（需要 Python 3.9+，首次运行自动装依赖；exe 存在时优先启动 exe）。

也可以手动运行源码：

```
python main.py
```

### 重新打包 exe

```
python -m PyInstaller --noconfirm --clean --onefile --windowed \
    --name "每日时事新闻汇报" --icon icon.ico --collect-data ttkbootstrap main.py
```

构建产物在 `dist/`，PyInstaller 及其依赖的 wheel 已放在 `wheels/` 目录可离线安装。

## 配置

配置文件 `config.json`（首次运行后自动生成）：

```json
{
  "theme": "news-dark",       // 主题：news-dark 深色 / news-light 浅色
  "refresh_minutes": 30,      // 自动刷新间隔（分钟）
  "always_on_top": false      // 启动时是否窗口置顶
}
```

界面主色调为中性灰（已去除 ttkbootstrap 默认的蓝色调），两个主题均为内置主题的去蓝定制版。

## 常见问题

- **显示「离线缓存」**：网络不可用或接口临时故障，显示的是本地缓存；
  点「刷新」重试即可。所有数据源均为免费公开接口，偶尔会有波动。
- **程序异常退出**：同目录下会生成 `error.log`，可发给我排查。

## 项目结构

```
├── main.py           # 图形界面主程序
├── news_service.py   # 数据层：接口拉取、解析、缓存、降级
├── 启动.bat           # 一键启动脚本
├── requirements.txt  # 依赖清单
├── config.json       # 用户配置（自动生成）
├── wheels/           # 依赖离线安装包
└── data/cache.json   # 本地缓存（自动生成）
```
